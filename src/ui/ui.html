保存规则
路径规则与 Figma 一致：图层名里的 / 表示新建一层文件夹，祖先图层名作为更外层目录。
例：画框 0911 → 图层 1555/HR面霜-11主图-1
　→ 保存为 0911/1555/HR面霜-11主图-1.jpg
· 选中 1 个目标：先选文件夹，按规则自动建子目录后直接存图片。
· 选中 多个目标：自动打包为 zip（压缩包内保留目录结构），再选保存位置。
· PNG 不支持质量参数，原样输出；JPG / WebP 按质量重编码。
