# 使用说明

## 安装与更新

从仓库下载 ZIP，解压后在 Figma 桌面端的插件开发菜单中导入根目录 `manifest.json`。安装目录至少需要：

```text
FIGMA工具箱/
├── manifest.json
└── dist/
    ├── main.js
    └── ui.html
```

更新时关闭插件，用新版文件替换原目录内容，再运行插件。开发者修改源码后先执行 `npm run check`。

## 字体混排

1. 选中文本图层，也可以选择包含文本的画框或分组。
2. 切换到“字体混排”。未选预设时，面板自动读取选区属性。
3. 分别选择中文、英文字体及字重，填写字号和颜色。
4. 点击“应用字体混排”，查看状态栏结果。

### 字号识别

字号检查全部选中文本，按中英文分别汇总。例如中文均为 24、英文均为 12，分别显示 24 和 12；中文包含 24 和 30 时，中文显示“混合字号”。空白字符不参与字号汇总。同类字号不一致时留空应用会保留其原字号；填写数字则将该类字符统一为指定字号。

纯中文或纯英文文本会把已有语言的字号补到另一侧。字体和颜色读取该语言的首个有效字符，不表示同类字符的所有字体、颜色都相同。

### 预设

- 保存：配置完成后输入名称，点击“保存为方案”。
- 载入：从顶部列表选方案，再点击“应用字体混排”。只选方案不会修改文档。
- 更新：选方案后调整参数，点击更新按钮；名称框可用于重命名。
- 取消：再次点击列表中标有“当前”的方案，恢复选区自动识别。
- 分享：点击“导出全部”生成 JSON，接收者通过“导入方案”导入。

选中方案期间自动识别不会覆盖方案值。因此查看文档实际字号前，需要取消当前方案。

### 字体加载

启动时读取设备字体列表，并提前加载已保存预设需要的字体。点击应用会复用已完成或正在进行的加载。第一次启动、字体服务较慢或新选字体尚未加载时，仍可能需要等待。缺失字体会显示名称；目标字体超时时不会继续修改文档，请按提示重试。

## 批量样式

1. 选择要修改的图形图层，切换到“批量样式”。
2. 开启需要修改的属性，并配置填充、描边、圆角或阴影。
3. 渐变可选择线性、径向、角度或菱形，并设置色标、角度。
4. 点击应用，查看处理结果。

批量样式不递归修改画框内部图层；要修改内部图形，请直接选中它们。样式方案与字体方案独立管理。

## 斜切

1. 选择目标图层，切换到“斜切”。
2. 设置 X/Y 角度或选择快捷角度，查看预览。
3. 应用后检查实际形状。

斜切以中心为锚点并保留旋转，分组会递归处理内部节点。X/Y 同时非零时，重新读取可能显示等效的单轴角度，这是变换分解的限制；自动布局也可能限制位置变化。

## 导出压缩

1. 选中需要导出的图层，切换到“导出压缩”。
2. 设置格式及面板提供的导出选项；JPG/WebP 可调整质量。
3. 点击导出并保存文件；多目标自动打包 ZIP。

图层名中的 `/` 表示目录层级。例如画框 `0911` 中的图层 `1555/主图`，对应目录路径 `0911/1555/主图`，导出时附加所选格式扩展名。同名路径会自动区分，非法文件名字符会清理。

## 常见问题

**选择其他文本后，面板仍显示旧字号？**
先检查顶部是否选着预设。取消预设后再查看识别结果。若出现“混合字号”，说明同一语言包含多个字号。

**导入别人的预设后不能应用？**
确认对方使用的字体在自己的设备或 Figma 中可用。预设 JSON 不含字体文件。

**如何向别人分享插件？**
发送 `manifest.json` 与完整 `dist/`；如需共享方案，再发送插件导出的 JSON。无需发送 `node_modules`。

**如何报告问题？**
记录选择的图层类型、是否使用预设、操作步骤及状态栏原文，并说明 Figma 环境与涉及字体。不要把本地模拟测试通过当作所有设备均已验证。
